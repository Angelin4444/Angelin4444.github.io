## Overview

Gamerex is a multi-page gaming website developed as my first web development project using HTML, CSS, and JavaScript. The project was created to explore front-end web development concepts, including page navigation, interactive user interfaces, and responsive design fundamentals.

Inspired by modern gaming platforms, Gamerex provides a visually engaging experience for gamers by showcasing popular titles such as Mobile Legends, Valorant, League of Legends, and Genshin Impact.

## Features

* Multi-page website structure
* Dedicated Home, Shop, and Contact pages
* Interactive user interface built with JavaScript
* Gaming-themed design and animations
* Game showcase section featuring popular titles
* Organized navigation system for smooth browsing
* Custom styling using CSS

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Learning Outcomes

This project helped me gain practical experience in:

* Structuring multi-page websites
* Designing user-friendly interfaces
* Implementing navigation between pages
* Creating interactive web elements with JavaScript
* Organizing and maintaining front-end project files

## Note

This project was developed as part of my web development learning journey and represents my first complete website project. While it is not fully responsive, it served as an important step in understanding the fundamentals of modern web development and front-end design.
